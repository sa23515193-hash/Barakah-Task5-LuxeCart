LuxeCart is a modern frontend e-commerce application developed with React and Redux Toolkit. It demonstrates centralized state management and essential shopping cart functionality in a responsive storefront.

## Features

- Product listing interface
- Add products to the cart
- Remove products from the cart
- Increase and decrease item quantities
- Automatically calculate cart totals
- Centralized state management using Redux Toolkit
- Responsive shopping interface
- Component-based React architecture

## Tech Stack

- React
- JavaScript
- Redux Toolkit
- React Redux
- Tailwind CSS
- Vite

## Getting Started

Install the dependencies and start the development server:

bash
npm install
npm run dev


## Production Build

bash
npm run build
npm run preview


## Deployment

The application is designed for static hosting and can be deployed to GitHub Pages or another static hosting service. Configure the Vite base path for the repository before deployment.

## Architecture

The frontend uses Redux Toolkit to manage shopping cart state. Product and cart interactions run in the browser without requiring a backend API.

## Project Type

Frontend-only e-commerce demonstration. It does not include real payments, server-side orders or a production inventory system.
